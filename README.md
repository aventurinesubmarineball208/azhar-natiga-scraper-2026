## ⚙️ Settings Explained

- **Concurrency (Max Parallel Requests):** This controls how many searches happen at the same time. Set it lower (like 1-2) for slower, more reliable searches, or higher (like 5-10) for faster results if your internet connection is good
- **Timeout:** How long the tool waits for a response before moving on. Increase this if searches often time out
- **Retry Attempts:** How many times to retry a failed search before giving up

## ❓ Troubleshooting

**Problem:** No results found for a search
**Solution:** Double-check the national ID or seat number for typos. Make sure you're using the correct format (usually 14 digits for national ID). The exam results may not be published yet for that specific student.

**Problem:** Searches are very slow
**Solution:** Lower the concurrency setting to 1-2. Check your internet connection speed.

**Problem:** Tool doesn't open in browser
**Solution:** Make sure you're using a modern browser like Chrome, Firefox, or Edge. Try right-clicking the file and selecting "Open with" then choosing your browser.

**Problem:** Results show error messages
**Solution:** The website might be temporarily down. Wait a few minutes and try again. You can also increase the timeout setting.
